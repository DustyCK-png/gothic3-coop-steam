# Gothic 3 — кооператив через Steam

Экспериментальная сборка G3 Together с отдельным Steam-ретранслятором. Нужны собственная Gothic 3 Steam, Community Patch 1.75.14 и одинаковая сборка мода у обоих игроков.

## Сборка

Установите Git, CMake, Visual Studio с C++ и Windows SDK. Выполните bootstrap.ps1, затем команды из README.md. Сборка — 32-битная. Исходники игры и готовые движковые DLL не входят в репозиторий.

## Установка

1. Создайте отдельную копию игры. Сохранения предварительно скопируйте в резервную папку: обычная копия игры продолжает использовать общий профиль Windows.
2. Поместите Script_G3Together.dll в scripts, пример INI из examples — в корень под именем g3together.ini. У игроков должны быть разные постоянные name.
3. В корне создайте SteamLink. Поместите туда G3Steam.exe и официальную steam_api.dll x86, полученную из разрешённого источника; steam_appid.txt должен содержать 480. Имитационную DLL из тестов не используйте.
4. Steam-Host.cmd и Steam-Join.cmd из папки steam положите в корень кооперативной копии.

## Подключение

Оба запускают Steam под разными аккаунтами, добавленными в друзья. Хост запускает Steam-Host.cmd, ждёт номера лобби и выбирает новую игру. Друг запускает Steam-Join.cmd, выбирает хоста и также начинает новую игру. Окна лаунчеров остаются открытыми.

IP и порт вручную для этого режима менять не требуется. Адрес 127.0.0.1 в INI правильный: игра обращается к локальному лаунчеру, а он передаёт пакеты через Steam. В Steam может показываться Spacewar (AppID 480). Приглашения через оверлей отдельно не проверены; используйте выбор друга в консоли.

## Проверки и ограничения

Два настоящих клиента видели второго героя и передавали четыре перемещения через localhost, затем через имитацию Steam API. Ошибки положения: 9.2, 2.5, 7.9 и 24.0 см при допуске 50 см. Исходные сохранения не изменились. Проверены настоящий Steam API и создание/закрытие лобби. Интернет между двумя аккаунтами, полное прохождение, бои, квесты и сохранение/переподключение здесь не подтверждены.

Для тестов предусмотрены исходники перенаправления профиля (isolation). Они меняют только явно отмеченную тестовую копию; подробности и команды — в README.md. Не переносите пропатченные движковые DLL в основную установку. Файл qa-enable.txt включает тестового бота и должен отсутствовать в обычной игре.
